´crear-dasboard´ es una skill que permite crear dashboards personalizados para visualizar datos de manera efectiva. Con esta skill, los usuarios pueden seleccionar diferentes tipos de gráficos, tablas y widgets para representar la información de manera clara y concisa. Además, ofrece opciones de personalización para adaptar el diseño del dashboard a las necesidades específicas del usuario.

1. Utilize: streamlit, pandas, matplotlib, seaborn, plotly.
2. Los dashboards tiene que usar el estilo de la siguiente página: https://live-well-drilling-metrics.plotly.app/
3. Crea graficas, tablas, estadística descriptiva.
